# D · Glossary { #glossary }

## D.1 · The guide's words { #terms }

| word | what it means |
|---|---|
| **agent** | the DCS server's hook and its sender, which record missions and send them to the Ready Room (chapter 10) |
| **archived** | a member who has left the roster, whose profile and history remain |
| **crest** | a squadron's image; **emblem**: the wing's |
| **daily 6 a.m. pass** | the daily update of the Discord messages ([§9.2](09-running-on-its-own.md#daily-pass)) |
| **digest** | the Discord message that announces the schedule for the next two weeks, kept up to date by the Ready Room |
| **founding administrator** | a Discord account named in `ADMIN_IDS`: it always gets in and cannot lock itself out |
| **Free Agent** | a member who has access without holding a squadron role |
| **hook** | a script that DCS loads when it starts, from `Scripts\Hooks\` |
| **migration** | the change to the database structure that a release brings, applied at start-up after a backup |
| **release** | a published version of the Ready Room, for example `RR-V1.0.0` |
| **roll call** | the reading of the Discord server's members and their roles, which keeps the roster up to date ([§8.4](08-first-settings.md#roll-call)) |
| **`.rrlog`** | a mission's text file, written by the agent's hook |
| **token** | a secret string that proves who is speaking: the bot's, the agent's, the manual updates' |
| **volume** | a storage space managed by Docker, which outlives the containers (appendix B) |
| **wing** | the whole group, which the Ready Room serves; **squadron**: one of its units, attached by a Discord role |
| **wing time zone** | the time zone in which the Ready Room counts days and hours ([§7.5](07-first-start.md#time-zone)) |
